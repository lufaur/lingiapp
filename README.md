# Lingi Legal Pages

Legal and landing pages for Lingi, the on-device translator app for iOS, hosted on GitHub Pages.

## Pages

- **index.html** - Landing page with app info
- **privacy.html** - Privacy Policy
- **terms.html** - Terms of Use

## Live URLs

- Site: https://lufaur.github.io/lingiapp/
- Privacy: https://lufaur.github.io/lingiapp/privacy.html
- Terms: https://lufaur.github.io/lingiapp/terms.html

No custom domain yet — these are the URLs referenced from `Theme.LegalURLs` in the Lingi iOS app.
